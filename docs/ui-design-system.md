# Tyco UI/UX Design System

Scope: every page from the front page onward — logged-out (marketing/landing) and
logged-in (app) experiences.

## 1. Library stack (source of truth)

Use only these as reference/source for components. No AI-vibe-coded UI kits
(component dumps generated by AI page-builders / "one-shot" AI UI generators,
unmaintained AI-scraped clones, etc.) — every component must trace back to a
hand-built, actively maintained, non-AI-generated library.

| Layer | Library | Use for |
|---|---|---|
| Core components | [HeroUI](https://heroui.com/) | buttons, forms, nav, modals, tables |
| Motion / micro-interactions | [smoothui](https://smoothui.dev/) | transitions, hover/press states, scroll effects |
| Page sections | [blocks.so](https://blocks.so/) | hero, pricing, footer, feature-grid layouts |

Underlying deps these libraries rely on (Tailwind CSS, Radix UI, Motion/Framer
Motion) are allowed. Existing GSAP + Lenis usage should be migrated to
smoothui-driven motion where equivalent, unless kept for scroll-smoothing only.

## 2. Color

Keep the existing brand tokens in `src/app/globals.css` (ink / paper / red) —
do not invent new colors. Shift the whole palette lighter/brighter, staying
dark (not a light/white theme):

- Background stays dark but lifts several shades off near-black `--ink`
  (`#100e0d`) — a softer, brighter charcoal, `color-scheme: dark` remains.
- Red accent (`--red` / `--red-bright`) stays the accent, tuned brighter to
  read well against the lighter dark ground.
- All colors continue to flow through CSS custom properties — no hex values
  hardcoded in components.

## 3. Typography

Keep `--font-display` (Fraunces) and `--font-body` (Jost) tokens — apply them
consistently on every page, no per-page font overrides.

## 4. Motion

Every page includes at least one non-AI-library transition/animation
(entrance, hover, or scroll-triggered) sourced from smoothui, applied through
the existing `--ease` / `--dur` tokens for consistency. smoothui is the sole
motion library going forward — GSAP and Lenis are being phased out and
replaced as pages are touched.
